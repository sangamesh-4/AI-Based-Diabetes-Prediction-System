## 📌 Overview  
This project is an AI-powered web application that predicts whether a person is diabetic or not based on medical input parameters.  
It integrates Machine Learning models with an interactive Streamlit web interface for real-time predictions.

---

## 🎯 Objective  
To develop an intelligent system that assists in the early detection of diabetes, helping users take preventive healthcare measures.

---

## 📊 Dataset Information  
The model is trained on a diabetes dataset containing the following features:

- 🧾 Pregnancies  
- 🍬 Glucose  
- 💉 Blood Pressure  
- 📏 Skin Thickness  
- 💊 Insulin  
- ⚖️ BMI  
- 🧬 Diabetes Pedigree Function  
- 🎂 Age  

### 🎯 Target Variable  
- `0` → Non-Diabetic  
- `1` → Diabetic
